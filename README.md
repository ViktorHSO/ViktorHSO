## Projetos

### [API de Tarefas](https://tarefas-viktorhso.onrender.com)

API REST em Java e Spring Boot para gerenciar tarefas pessoais, com cadastro, login por token JWT, prioridades, prazos, filtros, paginação e um resumo do que está atrasado. Cada usuário só enxerga as próprias tarefas. O banco é versionado com Flyway e há testes de integração rodando no GitHub Actions. O site em React e TypeScript transforma cada tarefa num número de peito de corrida e tem painel de progresso. Roda com Docker Compose e está publicado no Render com banco MySQL no TiDB Cloud.

Java, Spring Boot, Spring Security, JWT, MySQL, Flyway, React, TypeScript, Tailwind CSS, Docker, GitHub Actions

### [Biblioteca de Mangás](https://biblioteca-de-mangas.onrender.com)

Aplicação completa para catalogar e ler mangás. A API REST em FastAPI tem cadastro de obras e capítulos, envio de capas e páginas, busca com filtros combináveis, paginação, ranking por visualizações e login de administrador com JWT, com testes automatizados em pytest rodando no GitHub Actions. O site em React tem catálogo, ranking, busca rápida e leitor de capítulos. Roda com Docker Compose e está publicado no Render com banco MySQL no TiDB Cloud.

Python, FastAPI, SQLAlchemy, MySQL, React, Tailwind CSS, Docker, GitHub Actions

[Ver o site](https://biblioteca-de-mangas.onrender.com) | [API (Swagger)](https://biblioteca-de-mangas-api.onrender.com/docs) | [Código](https://github.com/ViktorHSO/biblioteca-de-mangas)

### [PokéRadar](https://viktorhso.github.io/pokeradar/)

Pokédex em React Native e Expo que consome a PokéAPI, com versão web publicada pelo GitHub Actions. Mostra os 1025 Pokémon com busca, filtros por tipo e geração, favoritos e detalhes em abas com atributos, cadeia de evolução e fraquezas. Começou como atividade de aula.

React Native, Expo, JavaScript, GitHub Actions
